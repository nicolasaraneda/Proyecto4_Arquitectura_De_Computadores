# Una variante por línea:
#   etiqueta | fuentes | definiciones | parámetros | referencia | descripción
# fuentes:
#   repo        rtl/ del repositorio, sin tocar (sw/trade.hex)
#   proto       el prototipo del barrel de factibilidad/a_barrel, sin tocar
#   barrel      el SoC integrado de esta carpeta (rtl/pochoco_soc.v y
#               rtl/espino_barrel_core.v), con la regla base en el hilo 0
#   barrel_dir  lo mismo con la memoria sin emulación de lectura durante
#               escritura (atributo no_rw_check en una copia de pochoco_ram.v)
#   seg         el segmentado con la extensión (core de d_isa) y el vigilante
#               (SoC y esclavo SPI de e_warmboot), sin archivos de esta carpeta
# referencia: etiqueta contra la que se calcula la columna "agrega".
# Las líneas "= título" abren un grupo en el informe. La etiqueta de
# tools/medir_variante.sh es fact2_i_ETIQUETA.
